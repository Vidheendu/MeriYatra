# MeriYatra 🚌

**MeriYatra** is a modern, mobile-first web application designed to make public transit hassle-free. It provides a clean and accessible interface for passengers to track their local city buses, autos, and cabs in real-time.

## Features ✨

- **Live Transit Tracking:** View simulated real-time GPS locations of transit vehicles on an interactive map.
- **Smart Location Search:** Powered by the OpenStreetMap API for accurate, real-world Indian location auto-suggestions.
- **Bilingual Interface:** Instant toggle between English and Hindi for maximum accessibility.
- **Dual Workflows:** Dedicated login and registration flows tailored specifically for Passengers and Transit Drivers.
- **Mobile-First Design:** Fully responsive layout built with Tailwind CSS, ensuring a premium experience on any smartphone.

## Tech Stack 🛠️

- **Frontend Framework:** React (Vite)
- **Styling:** Tailwind CSS
- **Mapping:** Leaflet (`react-leaflet`)
- **Icons:** Lucide React
- **Location Data:** Nominatim OpenStreetMap API

## Getting Started 🚀

1. **Install dependencies:**
   ```bash
   npm install
   ```
2. **Start the development server:**
   ```bash
   npm run dev
   ```
3. Open `http://localhost:5173` in your browser.
